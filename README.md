# Estructura-de-datos-y-Arreglos
En donde se va a aprender sobre la estructura de datos y arreglos en java y c++ 
Son formas de organizar y almacenar información en un programa; los arreglos son un tipo de estructura de datos que permite guardar varios elementos del mismo tipo en una sola variable, usando posiciones llamadas índices.
Las estructuras de datos son formas de organizar, almacenar y gestionar información dentro de un programa para facilitar su uso.
En programación, los datos no se guardan de manera desordenada. Se organizan siguiendo ciertas reglas para que sea más fácil acceder a ellos, modificarlos y procesarlos.
Una estructura de datos define:
•	Cómo se almacenan los datos en la memoria 
•	Cómo se pueden utilizar dentro del programa
